Per request, medians of each server's runs. user us, sys us: the server's CPU time. instr, IPC: instructions and instructions per cycle, u in the server's own code, k in the kernel on its behalf. L1i miss, br miss: instruction cache refills and mispredicted branches in its own code. syscalls: all of them; reads, writes, epoll waits: those of each kind; SQEs, CQEs: io_uring submissions and completions; ZC sends: those submitted as SENDMSG_ZC. Counts are the server process's: the kernel's network work in interrupts and softirqs is not in them.
segs in, segs out: the server machine's TCP segments.
